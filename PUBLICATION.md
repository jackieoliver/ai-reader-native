# Publication scope

Built by Jackie Oliver at Haptica. This edition retains the development commit sequence and version tags after correcting shared-account author metadata and removing `artifacts/` and `.codex/` from every commit. The excluded debugging captures contained account information and private chat UI. The original repository remains private.

Published material consists of application code, tests, generic text-transformation prompts, build scripts, and engineering documentation. Provider keys must be supplied locally. No credentials, private conversation exports, or real desktop screenshots are bundled. The retained history was secret-scanned and reviewed for account identifiers and private machine paths before publication.

Runtime credentials and captured clipboard text are separate from source code; do not commit them. Existing external-provider attribution is preserved. This repository does not claim authorship of Anthropic or Cartesia services.
